## 🧠 Deloitte Australia Data Analytics Job Simulation

As part of the **Deloitte Australia Data Analytics Job Simulation**, I worked with a company named **Deloitte Australia** that recently partnered with a client called **Daikibo**.  

⚙️ Using a **data unification algorithm**, Daikibo consolidated all **telemetry data** collected from its four factories:  
- 🏭 **Daikibo Factory Meiyo** (Tokyo, Japan)  
- 🏭 **Daikibo Factory Seiko** (Osaka, Japan)  
- 🏭 **Daikibo Berlin** (Berlin, Germany)  
- 🏭 **Daikibo Shenzhen** (Shenzhen, China)  

📡 Each location operates **9 types of machines**, sending data messages every **10 minutes**. Daikibo collected this data for an entire month (**May 2021**) and shared it in a single **JSON file** for analysis.  

🔍 The client’s goal in gathering telemetry data was to answer two key questions:  
1️⃣ In which **location** did machines break the most?
2️⃣ Which **machines** broke most often in that location?
